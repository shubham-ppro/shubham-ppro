## About
I'm a Lead Back-End Engineer focused on building authorization and configuration management systems for payment processing. My current work centers on designing and implementing a fine-grained permission model that will enable external customers — PSPs, merchants, and introducers — to securely access PPRO's portal with granular, role-based access control. I enjoy working on new challenges, exploring modern architectures, and continually growing in this career through hands-on delivery.

## Current work
Building PPRO's Global Auth model — a domain-resource-action permission system that replaces coarse-grained roles with fine-grained, service-level permissions. This involves designing the data model, building GraphQL APIs, integrating with AWS Cognito for authentication, consuming event-driven data via Kinesis, and coordinating across backend, frontend, and design teams to ensure the backend supports ambitious UI requirements.
